# 🪨📄✂️ Rock, Paper, Scissors Game

> Классическая игра "Камень, Ножницы, Бумага" с компьютером. Первый до трёх побед!

---

## ✨ Демо

![Скриншот игры](screenshot-game.png)

---

## 🎮 Как играть?

1. Выбери **Rock** (Камень), **Paper** (Бумага) или **Scissors** (Ножницы)
2. Компьютер делает случайный выбор
3. Узнай результат раунда!
4. Первый, кто наберёт **3 очка** — побеждает!

---

## 📋 Правила

| Действие | Результат |
|----------|-----------|
| 🪨 Rock vs ✂️ Scissors | Rock побеждает! |
| ✂️ Scissors vs 📄 Paper | Scissors побеждают! |
| 📄 Paper vs 🪨 Rock | Paper побеждает! |
| Одинаковый выбор | Ничья! |
